# Android Desk · 安卓原生桌面

**产品形态：** 运行在安卓平板和安卓手机上的**原生桌面**（Launcher / 主屏幕）。把它设为默认主屏幕之后，按 Home 回到的就是这张桌子。DSH Go、DeepDeep 这类手机 AI 助手可以在桌面上驻留显示，并在你授权后和你一起操作这张桌面。

**不是** 一个全屏看板应用，也**不是** [iPad Desk](https://github.com/skydream9527-ctrl/ipad-desk) 的安卓版。iPad Desk 是 iPad 上的应用；本项目是安卓系统主屏幕级别的桌面。

## 本轮要交付的功能

| 功能 | 一句话 |
|---|---|
| 桌面本体 | 壁纸、分页网格、底栏 / 任务栏、应用抽屉、长按拖动整理、可设为默认主屏幕 |
| 回到系统桌面 | 一键临时回到原来的桌面；也能跳到系统设置换回默认 |
| 从手机添加应用 | 桌面上放什么由用户挑；四条添加路径；安装卸载自动同步 |
| 应用管理页 | 一页管全部应用：搜索、筛选、添加 / 移除、隐藏、单独设置 |
| 图标样式 | 6 种外形 × 6 种风格，可调大小与主题色，支持单个应用单独设置 |
| 人机协同 | 用户授权的助手可以请求翻页、整理图标、打开应用；改动前先问用户，随时可停；助手做了什么都看得见 |

这张桌面**不内置大模型、不联网**。助手是用户另外安装的应用。

## 两种形态

| 形态 | 说明 |
|---|---|
| 启动器形态 | 经典主屏幕：壁纸、图标分页、底栏、应用抽屉。打开应用后离开桌面，按 Home 返回。**本轮做的是这个。** |
| 桌面窗口形态 | 在系统支持自由窗口 / Desktop Windowing 的设备上，应用以窗口开在桌面上，助手与窗口同屏。能否启用以 W0 实测为准，本轮不做。 |

| 模块 | 职责 | 状态 |

| `host` | 助手注册、协议解析 | 已完成，有单测；请求处理管线待做 |

| `sdk` | 给第三方助手的协议常量 | v1 已定 |
| `app` | 桌面 APK | 骨架已写，能编译，未实机验证；多数界面待做 |
| `sample-agent` | 样例助手 | 未开始 |
