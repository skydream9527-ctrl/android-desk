# Android Desk · 安卓原生桌面

**产品形态：** 运行在安卓平板和安卓手机上的**原生桌面**（Launcher / 主屏幕）。把它设为默认主屏幕之后，按 Home 回到的就是这张桌子。DSH Go、DeepDeep 这类手机 AI 助手可以在桌面上驻留显示，并在你授权后操作桌面去互动。

**不是** 一个全屏看板应用，也**不是** [iPad Desk](https://github.com/skydream9527-ctrl/ipad-desk) 的安卓版。iPad Desk 是 iPad 上的应用；本项目是安卓系统主屏幕级别的桌面。

## 两种形态

| 形态 | 说明 |
|---|---|
| 启动器形态 | 经典主屏幕：壁纸、图标分页、底栏、应用抽屉。打开应用后离开桌面，按 Home 返回。这是手机以及「系统不支持自由窗口」时的默认。 |
| 桌面窗口形态 | 在系统支持自由窗口 / Desktop Windowing 的设备上，应用以窗口开在桌面上，助手与窗口同屏。能否启用以 W0 实测为准。 |

## 代码框架

[`AndroidDesk/`](AndroidDesk/) 是产品代码骨架。当前阶段与 iPad Desk 仓库类似：**把不依赖实测结论的模型与规则做实，把桌面窗口、无障碍注入等平台实现留成骨架。** 详见 [AndroidDesk/BUILD.md](AndroidDesk/BUILD.md)。

| 模块 | 职责 | 状态 |
|---|---|---|
| `core` | 桌面布局模型、助手绑定、确认闸门、HOME 角色状态 | 纯 Kotlin，可在 JDK 上单测 |
| `host` / `client` | 匹配、权限状态、壳层映射的纯逻辑 | 骨架，随 W0 补全 |
| `sdk` | 给第三方助手的协议草案 | 类型已建，IPC 待 M4 |
| `app` | 桌面 APK（`HOME` Activity） | 清单与入口已建，界面待 M1 |
| `sample-agent` | 样例助手 | 占位，待 M4 |
| `w0probe` | 实测工具，不进产品包 | 计划说明已写 |

## 许可与第三方

本仓库不含 DSH Go 或其他第三方助手的源码。DSH Go 是社区项目，与 DeepSeek 无官方关联；是否协作接入取决于对方或其插件是否实现本仓库 SDK。
