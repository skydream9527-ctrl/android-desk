# Android Desk · 页面设计

> 版本：v1.0 · 2026-11-12（Asia/Shanghai）  
> 范围：桌面画布、抽屉、引导、设置、助手面板。这不是资讯 App 的「多 Tab 页」，而是一张桌面加上它的配套界面。

---

## 1. 桌面画布（主界面，产品本体）

### 1.1 结构（从上到下，启动器形态）

1. 系统状态栏（系统绘制，本桌面只让出 inset）  
2. 可选：预览模式横条「预览模式 · 尚未设为默认主屏幕」+ 按钮「设为默认」  
3. 桌面页：壁纸全铺；网格图标与文件夹；桌宠浮在网格之上（可拖到不遮挡常用图标的位置）  
4. 页指示器  
5. Dock：4–5 个常用应用，中间或右侧为应用抽屉按钮  
6. 系统导航区（系统手势条或三键，本桌面让出 inset）

平板任务栏形态：第 5 项改为任务栏（钉住的应用 + 已打开窗口的按钮 + 抽屉 + 搜索）。预览横条仍在。

### 1.2 状态

| 状态 | 表现 |
|---|---|
| 预览模式 | 顶条常驻，直到成为默认主屏幕 |
| 已是默认 | 无顶条，干净桌面 |
| 整理模式 | 长按空白或图标进入；图标可拖；出现「移除」「完成」 |
| 助手执行中 | 桌宠切换动作；任务栏或底栏旁出现小的「停止」 |
| 需要你来操作 | 面板或横条说明原因（如「请输入验证码」），助手停手 |

### 1.3 手势（以 W0-T1 结论修正）

- 非边缘左右滑：切桌面页  
- 从 Dock 上滑或点抽屉按钮：打开应用抽屉  
- 长按图标：快捷方式 / 移除 / 应用信息  
- 长按空白：壁纸、桌面设置、整理、添加小组件（小组件 M4+）  
- 拖桌宠：只改位置，不进网格占位（避免把图标挤乱）

### 1.4 空态

- 全新安装：预置少量系统应用图标（电话/设置/文件等，若存在）和一个「应用抽屉」的发现提示，不预装假的助手图标  
- 助手未安装：不在桌宠层放灰色幽灵；只在「助手」设置里列出可放置的助手

## 2. 应用抽屉

- 自上而下：搜索框、字母或网格（默认网格）、全部可见应用  
- 可从桌面打开，返回手势或下滑关闭，回到原桌面页  
- 长按可拖回桌面

---

## 3. 首次引导

单条路径，不超过三屏，禁止做成功能广告轮播：

1. 「这是一张安卓桌面，把它设为默认主屏幕之后，按 Home 就会回到这里。」  
2. 预览当前桌面缩略（直接进画布也可，推荐直接进画布 + 预览顶条）。  
3. 主按钮：「设为默认主屏幕」。次要：「先看看」，保持预览模式。

助手权限不在引导里一次性索取。

## 4. 设置（从桌面长按进入，或抽屉里的「桌面设置」）

分组：

| 分组 | 内容 |
|---|---|
| 主屏幕 | 设为默认（若还不是）、密度、页数、图标标签开关 |
| 底栏 / 任务栏 | 钉住的应用、是否显示搜索 |
| 壁纸 | 跳系统壁纸选择 |
| 助手 | 已安装助手列表、允许驻留、桌宠跟随（默认关）、与 DSH Go 桌宠并存提示 |
| 操控 | 无障碍开关入口、确认档位、一键查看「当前允许的操作」、风险说明 |
| 关于 | 写明：原生安卓桌面，不是看板应用；版本号 |

未实现的分组不出现。

---

## 5. 助手面板（协作模式）

- 从桌宠点一下打开，贴在桌宠附近，不铺满（手机宽度可用接近半屏的底部面板）。  
- 区域：状态一句、短对话或当前任务进度、确认卡、停止。  
- 「打开完整助手」按钮：在非协作或用户要进对方完整 UI 时，启动该应用（窗口形态下以窗口打开）。  
- 确认卡按钮文案用动词：「允许这次发送」「停止」，不用「OK」。

## 6. 文案表（简体，可直接用于实现）

| 情境 | 文案 |
|---|---|
| 预览顶条 | 预览模式 · 尚未设为默认主屏幕 |
| 设为默认按钮 | 设为默认主屏幕 |
| 用户取消系统选择器 | 还没有改过来。你可以随时在桌面设置里再试。 |
| 无障碍未开 | 要让助手点按桌面，需要打开无障碍。桌面本身可以照常使用。 |
| 不支持自由窗口 | 这台设备暂时不能在桌面上开窗口，应用会以全屏打开。 |
| 需要你来操作 | 需要你来操作：密码和验证码请你自己输入。 |
| 停止 | 停止 |
| 两只桌宠 | 这款助手自带桌宠。可以关掉它自己的，或关掉本桌面的，避免叠在一起。 |
| 已卸载 | 这个应用已经卸载，图标会从桌面拿走。 |
