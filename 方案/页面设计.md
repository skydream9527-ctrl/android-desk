# Android Desk · 页面布局设计

> 版本：v2.0 · 2026-11-12（Asia/Shanghai）  
> 取代：v1.0（同文件旧版）。v1.0 的方向与文案继续有效，本版补齐到可照图实现的程度，并加入应用管理、图标样式、回到系统桌面、人机协同的界面。  
> 范围：桌面画布、抽屉、应用面板、桌面菜单、应用管理、图标样式、设置、助手层、对话框。  
> 效力：视觉数值与界面文案冲突时以本文为准；功能规则以 [功能设计.md](./功能设计.md) 为准。  
> 这不是资讯 App 的「多 Tab 页」，而是一张桌面加上它的配套界面。

## 1. 全局规格

### 1.1 断点与形态

| 当前窗口宽度 | 壳 | 底部 | 面板最大宽度 |
|---|---|---|---|
| < 600dp | 手机 | 通栏底栏，4 应用槽 + 全部应用 | 满宽 |
| ≥ 600dp | 平板 | 居中任务栏（最大 640dp），6 应用槽 + 全部应用 | 底部面板、确认卡最大 560dp 居中；全屏页内容最大 720dp 居中 |

按**当前窗口宽度**判断，不按机型。分屏、折叠时即时切换。

### 1.2 层级（由下到上）

| 层 | 内容 |
|---|---|
| 0 | 系统壁纸（系统绘制） |
| 1 | 顶部 / 底部渐变暗化 |
| 2 | 桌面页图标 |
| 3 | 预览横条、页指示点、底栏 |
| 4 | 拖动中的图标、目标格高亮、「拿走」条 |
| 5 | 桌宠（仅 S1） |
| 6 | 助手状态条（S1、S2） |
| 7 | S2 抽屉 |
| 8 | S5 / S6 / S7 全屏页 |
| 9 | 确认卡（**所有界面之上**，仅低于系统级面板） |
| 10 | 底部面板（S3、S4、助手面板）、对话框、Toast |

### 1.3 安全区

所有界面铺满全屏（edge-to-edge），内容让出状态栏、导航栏、刘海 / 挖孔的安全区。壁纸与渐变暗化铺到屏幕边缘。

状态栏图标颜色：S1、S2 用浅色图标（壁纸上的白字）；S5–S7 在浅色主题下切换为深色图标。

### 1.4 颜色

画在壁纸上的元素用固定色（不随主题变）：

| Token | 值 | 用途 |
|---|---|---|
| `chrome` | `#101318` 40% 不透明 | 底栏底色 |
| `chromeStrong` | `#14171D` 80% | 预览横条、状态条、「拿走」条 |
| `chromeBorder` | 白 20% | 上述元素的 1dp 描边 |
| `onWallpaper` | 白 100% | 壁纸上的主文字、图标名称 |
| `onWallpaperDim` | 白 80% | 壁纸上的次要文字、空态提示 |
| `accent` | `#7FB0FF` | 助手高亮圈、当前选中 |
| `danger` | `#E5484D` | 停止、「拿走」条激活态、卸载 |
| `previewBadge` | `#F2A33A` | 预览模式圆点与按钮文字、「思考中 / 需要用户」 |
| `ok` | `#34C38F` | 「执行中」、成功 |
| `drawerScrim` | `#0E1116` 90% | 抽屉背景 |
| 顶部暗化 | 黑 30% → 透明，高 110dp | |
| 底部暗化 | 透明 → 黑 35%，高 200dp | |

全屏页（S5–S7）、底部面板、对话框用 Material 3 配色：跟随系统深浅色；Android 12+ 跟随壁纸动态取色；更低版本用 Material 默认配色。

### 1.5 字号

| 用途 | 字号 / 行高 | 字重 |
|---|---|---|
| 图标名称 | 12 / 14sp | 常规，白色，带 1px 下偏移黑 60% 阴影 |
| 横条、状态条正文 | 13sp | 常规 |
| 「拿走」条、Toast | 14sp | 常规 |
| 空态提示 | 15 / 22sp | 常规 |
| 列表主标题 | 16sp | 常规 |
| 列表副标题 | 13sp | 常规，次要色 |
| 分组标题 | 13sp | 中粗，主题色 |
| 页面标题（顶栏） | 20sp | 常规 |
| 确认卡正文 | 17sp | 中粗 |
| 「字母」风格的字 | 图标边长 × 0.44 | 半粗 |

### 1.6 圆角、间距、触控

| 项 | 值 |
|---|---|
| 底栏圆角 | 30dp |
| 横条圆角 | 16dp |
| 状态条 | 全圆角（高度一半） |
| 确认卡圆角 | 24dp |
| 目标格高亮 / 助手高亮圈圆角 | 18 / 20dp |
| 底部面板 | Material 3 默认（顶部 28dp） |
| 页面左右边距 | 全屏页 16dp；底部面板 20dp；桌面页 8dp |
| 最小触控目标 | 48×48dp（页指示点例外：28×28dp，因为滑动才是主路径） |

### 1.7 动效

| 场景 | 动效 |
|---|---|
| 翻页 | 跟手，松手吸附；助手翻页用同一动画 |
| 图标换位 / 被助手移动 | 位置补间约 250ms |
| 抽屉开 | 自下方 1/3 处上滑 + 淡入，约 220ms；关为反向 |
| 全屏页开关 | 淡入淡出约 150ms |
| 拾起图标 | 放大到 1.12 倍、不透明度 95%，一次震动 |
| 助手高亮圈 | 出现后保持约 1.8 秒，消失不闪烁 |
| 桌宠「思考中」 | 缓慢缩放呼吸（1.0 ↔ 1.06，周期 1.4 秒）；桌面不可见时停止 |
| 打开应用 | 用系统默认启动动画，不自造过场 |

## 2. S1 桌面画布（手机）

### 2.1 布局

```
┌────────────────────────────────────────┐
│ 9:41                        ▲ ◢ ▮       │ 状态栏（系统绘制，本桌面让出）
├────────────────────────────────────────┤
│ ┌────────────────────────────────────┐ │
│ │ ● 预览模式 · 尚未设为默认主屏幕 设为默认│ │ ① 预览横条（仅预览模式）
│ └────────────────────────────────────┘ │
│                                        │
│   ▢        ▢        ▢        ▢        │
│  设置      相册      日历     联系人     │
│                                        │ ② 桌面页
│   ▢        ▢        ▢        ▢        │   列 × 行网格
│  文件      音乐     计算器     地图      │   横向分页
│                                        │
│   ·        ·        ·        ·        │
│                                        │
│   ·        ·        ·        · (◕‿◕)  │ ⑤ 桌宠（有已授权助手时）
│                                        │
│   ·        ·        ·        ·        │
│                                        │
│  ╭──────────────────────────────────╮  │
│  │ ● DSH Go：已翻到第 2 页     停止 │  │ ⑥ 助手状态条（有内容时）
│  ╰──────────────────────────────────╯  │
│                 ● ○ ○                  │ ③ 页指示点
│ ╭────────────────────────────────────╮ │
│ │   ◉      ◉      ◉      ◉     ⠿    │ │ ④ 底栏：4 应用 + 全部应用
│ ╰────────────────────────────────────╯ │
├────────────────────────────────────────┤
│               ▁▁▁▁▁▁▁                  │ 导航区（系统绘制，本桌面让出）
└────────────────────────────────────────┘
```

纵向从上到下是一个列布局：① 横条（可无）→ ② 桌面页（占满剩余高度）→ ③ 页指示点 → ④ 底栏。⑤⑥ 浮在上层，不参与列布局。

### 2.2 各部分尺寸

| # | 元素 | 规格 |
|---|---|---|
| ① | 预览横条 | 外边距 左右 12、上下 6；内边距 左 14、右 4；高约 44dp；圆角 16；底色 `chromeStrong` + 描边。内容：8dp 琥珀圆点 · 间距 10 · 文案（13sp，占满剩余宽度）· 文字按钮「设为默认」（`previewBadge` 色） |
| ② | 桌面页 | 左右内边距 8dp。格宽 = (页宽 − 16) ÷ 列数；格高 = 页高 ÷ 行数。图标与名称在格内水平垂直居中 |
| | 图标 | 基础边长 = min(格宽 × 0.62, 格高 × 0.56, 64dp)，不小于 36dp；乘以「图标大小」百分比 |
| | 名称 | 图标下 6dp；12sp 一行，左右留 2dp，超出省略 |
| ③ | 页指示点 | 行高 28dp，水平居中。每个点的触控区 28×28；当前页 8dp 白色实心，其余 6dp 白 45%。只有 1 页时不显示点，但保留 28dp 行高 |
| ④ | 底栏 | 外边距 左右 14、上 2、下 10；内边距 10；圆角 30；底色 `chrome` + 描边。总高 70dp。内部等分 5 列，每列居中一个 50dp 图标 |
| | 全部应用按钮 | 最右一列；50dp 圆，白 18% 底；内画 3×3 白色圆点阵（点阵边长 22dp） |
| ⑤ | 桌宠 | 见 §9.1 |
| ⑥ | 状态条 | 见 §9.2 |

### 2.3 手势

| 手势 | 位置 | 结果 |
|---|---|---|
| 横滑 | 桌面页 | 翻页 |
| 上滑 ≥ 56dp | 画布任意处（含图标上、底栏上） | 打开 S2 |
| 点按 | 图标 / 底栏图标 | 打开应用 |
| 点按 | 页指示点 | 跳到该页 |
| 长按约 400ms | 桌面页图标 | 拾起，见 §2.5 |
| 长按 | 底栏图标 | 震动，打开 S3 |
| 长按 | 桌面页空白 | 震动，打开 S4 |
| 拖 | 桌宠 | 移动桌宠 |
| 点按 | 桌宠 | 打开助手面板 |

屏幕左右边缘的系统返回手势区留给系统；桌面横滑以中部为准（W0-T1 实测后如需调整，在此表修正）。

### 2.4 状态

| 状态 | 与默认布局的差异 |
|---|---|
| 加载中（布局或应用列表未就绪） | 显示壁纸、空网格、底栏框；不显示空态提示。通常 < 300ms |
| 预览模式 | 显示 ① |
| 已是默认 | 不显示 ①，桌面页上移占位 |
| 桌面为空 | 第 1 页中央两行提示（15sp，`onWallpaperDim`，居中）：「桌面还是空的」「长按空白处，从手机里添加应用」 |
| 图标加载中 | 该图标位置显示同外形的白 20% 占位块，名称照常 |
| 拖动中 | 见 §2.5 |
| 助手相关 | 见 §9 |

### 2.5 拖动中

```
┌────────────────────────────────────────┐
│          ╭──────────────────────╮      │
│          │ 拖到这里，从桌面拿走 │      │ 「拿走」条：状态栏下 10dp，水平居中
│          ╰──────────────────────╯      │   手指移入 → 变红，「松手，从桌面拿走」
│                                        │
│   ▢        ▢      ┌╌╌╌╌┐     ▢        │ 目标格：浅色圆角框
│  设置      相册    ╎    ╎    联系人     │   （白 14% 底 + 白 40% 描边，内缩 6dp）
│                   └╌╌╌╌┘               │
│   ▢      （空）     ▢▢  ← 手指         │ 被拾起的图标：跟随手指，
│  文件               ▢▢                 │   中心在手指上方约半个图标处，1.12 倍
│                                        │ 原位置留空
│◄ 左右边缘各 30dp：停留 0.6 秒翻页     ►│
│                 ● ○ ○                  │
│ ╭────────────────────────────────────╮ │
│ │   ◉      ◉      ◉      ·     ⠿    │ │ 底栏：松手处在底栏内 → 钉入第一个空槽
│ ╰────────────────────────────────────╯ │
└────────────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 「拿走」条 | 仅在手指已移动后出现。内边距 左右 28、上下 14；全圆角；底色 `chromeStrong`，激活时 `danger`；14sp 白字。判定范围比可见范围各向外扩 18dp |
| 目标格高亮 | 手指在桌面页范围内且不在「拿走」条上时显示；跟随手指所在格 |
| 被拾起的图标 | 64dp，不带名称 |

任务栏**不显示正在运行的应用**，也不放搜索按钮（搜索在抽屉里）。

## 11. S9 对话框

统一用 Material 3 居中对话框：标题 20sp、正文 14sp、右下角文字按钮，危险操作的确认按钮用 `danger` 色。

| 对话框 | 标题 | 正文 / 内容 | 按钮 |
|---|---|---|---|
| 选择系统桌面 | 回到哪个桌面？ | 单选列表：每行一个桌面应用的名称。下方小字：「会记住这次的选择，可以在桌面设置里重新选。」 | 取消 ·（点列表项即确认） |
| 打不开系统桌面 | 打不开那个桌面 | 这台设备不允许直接切过去。可以在系统设置里更换默认桌面。 | 取消 · 去系统设置 |
| 始终免确认 | 不再询问？ | 打开后，被允许的助手打开应用、改动桌面都不会再问你。建议只在你看着屏幕的时候临时使用。 | 取消 · 不再询问（`danger`） |
| 清除单独样式 | 清除单独样式？ | 〈N〉个应用会改回跟随全局样式。 | 取消 · 全部清除 |

## 12. 首次启动

不做引导轮播。第一次打开直接进入 S1（预览模式），由预览横条承担说明与引导：

1. 用户看到真实桌面与预置图标。
2. 预览横条说明状态并提供「设为默认」。
3. 点「设为默认」→ 系统弹窗。

助手相关权限与说明不在首次启动出现；只在用户进入「助手与操控」时呈现。

---

## 13. Toast

使用系统 Toast，短时。只用于**用户自己发起的操作**的结果反馈；助手动作的反馈走状态条，不用 Toast。
