# Android Desk · 设计文档（原生桌面）

> 版本：v1.0 · 2026-11-12（Asia/Shanghai）  
> 分工：本文是视觉与交互基础；[页面设计.md](./页面设计.md) 是逐页规格。冲突时以页面设计为准。  
> 效力：产品形态以 [重构决策.md](./重构决策.md) 为准——这是桌面，不是应用皮肤。

---

## 0. 设计目标

| 目标 | 含义 |
|---|---|
| 一眼是桌面 | 壁纸、对齐的图标、底栏或任务栏、分页点。不能看起来像带大卡片的资讯 App |
| 助手是桌上的东西 | 桌宠站在壁纸之上、图标之旁；面板从桌面里长出来，而不是另开一个全屏聊天页把桌面盖死（短对话用面板，深任务才允许全屏或窗口） |
| 双形态一致 | 手机启动器形态与平板窗口形态共享同一套图标数据与色彩，只换壳 |
| 触控宽容 | 图标有效热区 ≥ 48×48 dp；分页指示器与停止按钮更大、更好按 |
| 诚实状态 | 预览模式、未设默认、无障碍未开、不支持自由窗口，都用短句说清 |
| 让壁纸说话 | 桌面 chrome 克制、半透明；不要用大块实心面板把壁纸遮死 |

## 1. 设备与形态

### 1.1 不用机型开关，用宽度

| 宽度（窗口/屏幕的最短边或当前 width） | 壳 |
|---|---|
| < 600 dp | 手机启动器：底部 Dock（4–5 个槽位 + 抽屉按钮）、底部页点 |
| ≥ 600 dp | 平板：底部或边缘任务栏（运行中/钉住的应用）、桌面图标可更疏 |

旋转、分屏时即时切换壳，不按「这是不是平板」的静态标志判断。

### 1.2 密度

设置提供 **自动 / 紧凑 / 宽松** 三种网格密度。这是格子大小，不是「手机/平板」开关。

### 1.3 桌面窗口形态的视觉

仅当系统能力允许时：应用窗口有简短标题条（最小/最大化仅在系统提供时显示）。助手桌宠不进入窗口标题条，始终属于桌面层。

## 2. 色彩与材质

常驻跟随系统浅色/深色（与壁纸对比不同于 iPad Desk 的「强制深色看板」——这里是真正的主屏幕，用户壁纸优先）。

| Token | 用途 |
|---|---|
| `chrome` | 底栏/任务栏：半透明，带一层细描边，可模糊壁纸（若设备性能允许；低端机关模糊） |
| `onWallpaper` | 图标标签：深/浅自动选，保证对比；必要时加薄阴影或半透明底，而不是改壁纸 |
| `accent` | 页点的当前页、可操作重点 |
| `danger` | 一键停止、敏感确认 |
| `previewBadge` | 预览模式顶栏提示，醒目但不像错误 |

语义色（成功/警告/等待确认）只用于助手状态与确认卡，不装饰普通图标。

---

## 3. 动效

- 翻页：跟随手指，松手吸附。不得做长时间装饰动画挡住第一次按 Home。
- 打开应用（启动器形态）：使用系统启动动画，不自造夸张过场。
- 桌宠：状态变化用短动作；息屏或离开桌面（且未跟随）时立即停动画。
- 整理模式：图标轻微可点提示，与常见启动器一致，不发明新的教学动画。

---

## 4. 文案语气

- 简体中文，短句。说「默认主屏幕」「预览模式」「需要你来操作」，不说「请配置您的 Launcher 角色」。
- 错误必须带下一步：例如「还不是默认主屏幕。点下面的按钮，在系统列表里选择 Android Desk。」
- 做不到的能力不要放禁用按钮，直接不渲染，并在设置的能力说明里写原因。

---

## 5. 无障碍（系统无障碍用户，不是「我们的操控服务」）

- 图标、底栏、抽屉、设置须有内容描述，可被 TalkBack 使用。
- 桌宠提供名称与当前状态（空闲/正在操作/需要你确认）。
- 助手正在通过操控面操作其他应用时，那些应用的界面语义不由我们保证——这要在说明里诚实写出。
