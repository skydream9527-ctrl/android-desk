## 2. 在有 JDK 的机器上跑 `core` 单测

`core` 是纯 JVM 模块，不需要 Android SDK：

```bash
cd AndroidDesk
./gradlew :core:test
```

若当前环境还没有 Gradle Wrapper 或 JDK，可先安装 Temurin 17+，再在本目录生成 wrapper。桌面 APK（`:app`）需要 Android SDK，在 Android Studio 中打开本目录构建。

建议：

- `compileSdk` / `targetSdk`：以本机 SDK 为准，规划为 35 或 36
- `minSdk`：26
- 语言：Kotlin，Gradle Version Catalog 管理版本
